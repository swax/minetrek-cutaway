# Assets and attribution

The MIT license covers this project's software. It does not grant rights to
Minecraft, third-party maps, texture packs, fonts, music or designs rendered by
users. This project is not affiliated with Mojang or Microsoft.

The public demo is synthetic and contains no third-party map or texture data.
It uses Pillow's default font. Other projects supply their own inputs through
configuration files; no historical map archive, raw chat log, soundtrack or
proprietary font is bundled.

The Classic block-face tile layout is documented in the code with a reference to
ClassiCube's block definitions. No game executable, old server class, mod JAR or
external program source is redistributed. Classic saves are decoded as data.

NumPy and Pillow are installed as dependencies under their respective licenses.
Development formatters and their plugins are installed separately under their
respective licenses.
The C# compiler, operating system fonts, OpenGL driver and FFmpeg are external
tools rather than files bundled with this repository.
